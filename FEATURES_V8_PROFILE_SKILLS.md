# v8 — Profile + Today's Priority + Skill Lab

## Profile governance
- Admin controls standard dropdown masters for Name, HQ, ABM, RM, Region.
- Player uploads photo and submits professional profile.
- Profile status defaults to Pending and can be approved by Admin.
- Player identity can be standardised instead of free text.

## Today's Priority
Admin can publish:
- Brand name
- Headline
- Daily input / SOP
- Brand logo
- Poster
- Reference link
- XP reward

Players see it under Today's Priority.

## Skill Lab
- Excel Formula Lab
- Communication
- Presentation
- Productivity
- XP for learning challenges

Initial Excel library:
SUM, AVERAGE, IF, SUMIFS, XLOOKUP, COUNTIFS, TEXTJOIN.

## Important next improvement
The current package has the backend endpoints for profile approval, but the admin approval queue UI should be expanded into a full approve/reject workflow in the next pass.
