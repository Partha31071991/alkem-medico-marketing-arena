# FREE-FIRST MODE

The portal is designed to minimize recurring content costs.

## Free learning sources
- Your own LBL and Detailing Story
- YouTube reference searches / embedded links
- Free/public medical education resources
- AI-generated drafts only when an AI API key is enabled

## AI cost control
AI generation is an Admin action. Generate once, review, approve, and reuse the saved content for all players.

## YouTube
The free mode uses YouTube search links rather than downloading or re-hosting videos. This avoids a video hosting bill. For automated in-portal video search via the YouTube Data API, a YouTube API key can be added later.

## Medical content
AI output is for learning support and must be reviewed against approved source material before publication.
